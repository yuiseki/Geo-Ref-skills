# レベル 2: 違うスタイル (2026-11-03)

## 条件

- 課題: `evals/matrices/level2-styles.json`。課題のスタイルは osm-bright と osm-carto、参照は osm-liberty。z15、900 x 700 画素。場所は大阪、金沢、旭川の郊外の畑。similarity と projective、強さ 0.5 と 1.0、種 3 と 4。陽性 48、陰性の対照 6。
- 解き方: feature-registration に勾配の強さの表現を足した後 (濃淡、だめなら勾配の強さ、それぞれ ASIFT への格上げ付き)。

## 失敗 1: 関門の穴 (gate_hole、2 件)

- 該当: 金沢の osm-bright の similarity 0.5 と projective 0.5、種 4。最大誤差 40 m と 61 m (画像の半径の 1.8% と 2.7%)。全ての関門を通った。
- 中身: GCP は 27 点と 19 点で、真の位置からのずれは全て 4.7 画素以内。GCP が画像の狭い帯 (凸包の割合 0.41 と 0.25) にあり、射影変換が GCP の無い縁で揺れた。
- 崩れた前提: leave-one-out の残差が小さければ、変換は画像の全体で正しい、と考えていた。残差は GCP のある所しか見ない。
- 試したこと: 1 点抜きの縁の揺れ (ジャックナイフ) と、GCP の広がり (凸包、最も遠い点) は、不正確な答えと正確な答えを分けられなかった。GCP のばらつきを係数の共分散を通して縁に伝えた標準偏差は分けられた。
- 直したこと: 関門 `edge_uncertainty` (縁の標準偏差 3 画素以下) を足した。それまでの 139 の答えで、1% を超える 5 件を全て落とし、正確な 134 件のうち 2 件を落とす。同じ答えを見て閾値を選んだので、別の課題で測り直す。

## 失敗 2: osm-carto (refused、24 件)

- 全て失敗を宣言した。誤った答えは出ていない。
- 局所の特徴では、濃淡、勾配の強さ、縮小 (0.5、0.35、0.25 倍) のどれでも、一対一の整合する対応が 4 以下だった (大阪の 1 課題で)。
- 地図の約束事 (水は青) を使い、色相で水のマスクを取り出して粗い全体の探索 (回転 3 度、縮尺 5% の総当たり、平行移動は正規化相互相関) をすると、osm-carto でも osm-bright でも、隅の誤差 36 画素以内で当たった。osm-fiord は背景が暗い青で、画像の 81% が水と判定されて外れた。
- 次: 水のマスクの粗い位置合わせの後、升ごとに独立に位置を合わせて GCP を作る道具 (未実施)。
