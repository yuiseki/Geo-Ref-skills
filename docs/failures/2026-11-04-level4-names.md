# レベル 4: 地名から場所と縮尺を求める、最初の評価 (2026-11-04)

## 条件

- 課題: `evals/matrices/level4-names.json`。osm-liberty (文字あり) の地図。名古屋、神戸、鹿児島、盛岡 (どれもそれまでの課題に無い)、ズーム 14、15、16、種 20。48 課題。
- 道具に渡すのは画像と国 (jp) だけ。枠もズームも渡さない。place-hint が地名を読み、自前の Nominatim で引き、名前の位置の組から縮尺、向き、ズーム、枠を求める (`scale_from_names`)。その枠とズームで参照を作り、feature-registration、外れた点の除去、関門と進む。
- 道具の調整は、開発用の東京、札幌、金沢の課題だけで行い、この 48 課題は一度だけ流した。

## 結果

| 結果 | 件数 |
|---|---:|
| ok | 6 |
| refused (全て place-hint の段) | 42 |
| gate_hole | 0 |

- ok の 6 件は全て盛岡 (z15 の 4 件、z16 の 2 件)。誤差の最大は 0.09〜0.46 m。
- 縮尺が求まった 7 件では、ズームの推定 (小数) は 14.93〜16.02 で、選んだズームは全て正解と同じだった。開発用の東京で見た 7〜11% の粗さは、ここでは見られなかった。
- 縮尺が求まって参照まで進んだ課題は、全て正解した。誤った場所や誤ったズームで関門を通った答えは無い。

## 止まった理由

| place-hint の段 | 件数 |
|---|---:|
| 名前が 3 つ以上そろわない (場所の段) | 29 |
| 名前が 3 つしか位置付けられない (縮尺の段) | 5 |
| 4 つ以上あるが、1 つの縮尺と向きにそろうのが 3 つ以下 (縮尺の段) | 8 |

- ズーム 14 では、12 件全てが止まった (11 件が場所の段、1 件が縮尺の段)。地図の文字が小さく少ない。
- 読んだ名前を 3 件だけ見た (この 3 件は、以後は見た課題として扱う):
  - 神戸 z15: 名前が途中で切れて読まれていた (KAIGANDOR、SOBEDOR、KANOCH、EDOR)。
  - 名古屋 z15: 6 つの名前が場所の段でそろったが、うち NAKA、CHIKUSA は区の名前。区の代表点は、地図に書かれた区名の位置から遠い。縮尺の段でそろったのは 3 つだった。
  - 名古屋 z14: 名前を 1 つしか読めなかった。

## 次に考えること (未実施)

- 名前の切れを減らす (tesseract に渡す前の拡大や二値化、行のつなぎ)。
- 面の大きい地物 (区、市) を、縮尺の段で使わないか、許容を地物の大きさに合わせる。Nominatim の boundingbox が使える見込み。
- 直したら、この 48 課題ではなく、新しい場所の課題で効果を測る。

## 2 回目: 地名の読み取りと照合を直した後、新しい場所で (2026-11-04)

直したこと (開発用の課題だけを見て): 灰色とカラーの両方で読む、地名とその下の「N-CHOME」の行をつなぐ、末尾の「!」を I と読む、丁目付きでしか登録されていない町を「1-chome」を付けて引き直す、近い候補をまとめる、Nominatim の件数の上限を 40 に、縮尺の当てはめで丁目付きの名前を重く扱い、そうでない名前は許容を広げる代わりに 5 つ以上を求める。

課題: `evals/matrices/level4-names-2.json`。京都、横浜、岡山、熊本 (どれもそれまでの課題に無い)、ズーム 14〜16、種 21。48 課題。一度だけ流した。

| 結果 | 件数 |
|---|---:|
| ok | 25 |
| refused (place-hint の段) | 19 |
| refused (関門) | 3 |
| error (Nominatim の 503) | 1 |
| gate_hole | 0 |

- ズーム別: z14 は 0/16、z15 は 11/16、z16 は 14/16。z14 は全て、地名が 3 つ以上そろわずに止まった。
- 関門で止まった 3 件は、どれもズームの推定が 1 段ずれていた。推定の小数が 15.07 や 15.10 のように整数のすぐ上に出ると、細かい側を選ぶ規則で 16 になり、参照の縮尺が 2 倍違って照合が足りなかった。京都の 1 件は、名前が 5 つで、推定が 14.72 (正解は 16 の地図) と大きく外れた。
- error の 1 件は、自前の Nominatim が一時的に 503 を返し、place-hint が落ちた。
- 1 回目 (6/48) とは場所が違うので、同じ課題での比較ではない。
