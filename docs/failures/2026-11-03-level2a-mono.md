# レベル 2a: 同じスタイルを灰色と二値にする (2026-11-03)

## 条件

- 課題: `evals/matrices/level2a-mono.json`。osm-liberty の z15、900 x 700 画素。場所はレベル 1 で使っていない大阪、金沢、旭川の郊外の畑。色の変え方は、そのまま、灰色、二値 (輝度を大津の閾値で白黒に)。歪みは similarity と projective、強さ 0.5 と 1.0、種 3 と 4。陽性 72 課題、陰性の対照 6 課題 (手がかりの枠を別の場所へ)。
- 解き方: レベル 1 の後の道具 (ASIFT への格上げ、一対一の整合する対応、gcp-refinement、関門)。参照は色付きの osm-liberty。

## 結果

| 色の変え方 | ok | refused |
|---|---:|---:|
| そのまま | 24 | 0 |
| 灰色 | 24 | 0 |
| 二値 | 16 | 8 |

- 陰性の対照 6 件は全て correct_reject。gate_hole と実行のエラーは 0。
- そのままの 24 件は、レベル 1 で道具を直した後、見ていない場所と種での測り直しになる。全て ok だった。
- ok の最大誤差は 0.13〜9.8 m。最大の 9.8 m は大阪の二値の projective 1.0 (GCP 34 点、中央値 2.1 m、画像の半径の 0.41%)。GCP の少ない隅での外挿と考えられる (未確認)。
- 灰色は、そのままと同じ結果だった (SIFT は内部で灰色にするので、予想どおり)。

## 失敗: 二値の畑 (refused、8 件)

- 該当: 旭川の畑の二値の 8 件全て。一対一の整合する対応は 1〜4。
- 崩れた前提 (仮説): 二値にすると、道路や畑の区画は背景と一緒に白に潰れ、残るのは文字と川とアイコンだけ。都市部 (大阪、金沢) では文字とアイコンが多いので解けたが、畑には照合に使える文字がほとんど無い。
- 失敗の宣言は正しい振る舞い。これを道具で解くべきかは、未決。白黒のコピーの地図では、道路は縁の線として残ることが多く、大津の閾値で全部潰れる模擬のほうが現実より厳しい可能性がある。
