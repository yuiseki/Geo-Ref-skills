# name-gcps

画像の照合 (feature-registration、cross-style-registration) は、地図と参照のタイルの見た目が似ていることを前提にする。国連の地図のような主題図は、OSM の描画と似ていないので、照合が成り立たない (2026-11-04、MONUSCO の照合は 0.221 < 0.3 で止まった)。この種の地図には、町が小さな輪の記号と名前で印刷されている。記号の位置と、OpenStreetMap にあるその町の位置の組を、基準点にする。

## 手順

```sh
uvx --with numpy --with opencv-python-headless python scripts/name_gcps.py image.png --out answer.json \
  --countrycodes xk,rs,mk,al,me --cache tmp/nominatim
```

- `--countrycodes` には、地図の国と、地図に写る隣の国を渡す。
- 終了コードが 0 なら、`answer.json` は登録の道具と同じ形の答え。georef-gates の関門に通す。1 なら失敗の宣言 (`status: failed`)。
- 地図が文字を持つ PDF (GIS や Illustrator の書き出し) なら、`--pdf map.pdf --page 1 --dpi 150 --box-px x0 y0 x1 y1` を足す (`box-px` は document-maps の候補の `from.box_px`)。OCR の代わりに文字の層を使い、記号フォント (ESRIDefaultMarker など) の字を町の記号として正確な位置で使う (`scripts/pdf_words.py`)。文字の層の語が 30 未満なら OCR に戻る。国連の 5 件では、通ったのが OCR の 3 件から 4 件 (MONUSCO も) に増え、GCP も増えた (UNMIK 18 から 34、MINUSCA 26 から 40)。
- 変換は既定で affine。関門で落ちたら、`--method projective` で流し直してよい (国全体の地図では投影の歪みが効くことがある)。

## 中身

1. 文字を読む。tesseract で、画像を 2、3、4、5 倍に拡大してそれぞれ読み、全部を使う。拡大率ごとに読める名前が違う (コンゴの地図で 110〜122、合わせて 157)。拡大した画像が 1 億画素を超える倍率は飛ばす (どれも超えるなら、収まる倍率で 1 回だけ読む)。5110 x 3910 の切り出しを 5 倍にすると 5 億画素で、8 GB の上限を超えて落ちた。
2. 名前らしいものを残し (place-hint と同じ `clean_name`)、自前の Nominatim で引く。表記が一致し、class が place (町、村) か administrative の boundary (町に結びついた自治体) の答えだけを残す。プリシュティナやリプリャンは boundary としてしか返らなかった。同じ名前の答えが 2 km 以内にあれば 1 か所とし、町の点があればその位置を使う。
3. 名前の位置から、相似変換 (縮尺、30 度以内の回転、平行移動) を当てる。名前と候補の組を 2 つずつ無作為に選んで仮説にし、画像の対角線の 3% 以内に候補が来る名前が最も多い仮説を採る。名前は町の横に書かれるので、許容は広い。6 つ未満しかそろわなければ失敗を宣言する。
4. 町の記号を探す (`ring_score`)。輪 (半径 3〜6 px)、中に点のある輪 (半径 4〜8 px、行政の中心)、塗りつぶした点 (半径 2.5〜4 px) の型との相関を取り、極大の位置を画素未満まで求める。塗りつぶした点は、縁が中心より明るいことを求める。輪の内側が輪より明るいことも求める (相関だけでは塗りつぶした四角も 0.66 で輪と同じくらいになった)。文字の o や e も輪に見えるので、読めた語の文字の上にある極大は除く。ただし、tesseract は町の輪を語の一部として読むことがある ("Srbicao"、"°Novi")。語の端にある輪のような文字は、それを除いた語も読めているか、文字でないときは、文字の箱から外す。
5. そろった名前のうち、大文字だけの名前 (国、州、地域。部隊の派遣国名も) は記号を持たないので除く。名前の前後に記号の文字が付いて読まれたもの ("‘Isiro"、"{Juba") は、その文字を除き、名前の箱もその分だけ縮める。3 文字の町の名前 (Wau、Bor、Yei) も、頭文字だけ大文字なら使う。残りの名前ごとに、名前の箱の外で、箱から文字の高さの 1.2 倍以内にある記号を候補にする。
6. 記号の候補と、名前の当てはめで許した場所の候補 (町の点か郡の中心か、など) から 1 組ずつ選んで、記号から町の位置への相似変換を RANSAC で当てる (許容は対角線の 0.5%)。名前の位置からの予測は、国の地図では 20〜40 px ずれ、そばの空港や鉄道の目盛りと区別できないため、記号の位置そのもので当てる。
7. 選んだ記号で変換 (既定は affine) を当て、最も外れた点を落としながら、全ての点が 2 px 以内に入るまで繰り返す。1 つの記号には基準点 1 つ (Kumanovo と、読み違えた Kumanove が同じ輪を使っていた)。
8. その変換で、読めた全ての町の名前 (名前の当てはめで外れたものも) について、記号と場所を選び直し、もう一度当てる (2 回)。国の地図では、投影の曲がりで、端の名前が相似変換から外れやすいが、端を押さえるのはその名前。12 未満しか残らなければ失敗を宣言する。

## 確かめたこと (2026-11-04)

国連の平和維持活動の地図 5 件で試した。この 5 件を見ながら作ったので、ここでの結果は効果の評価ではない。

| 地図 | 結果 |
|---|---|
| UNMIK (コソボ) | 関門を全て通った。基準点 18、LOO の最大 2.2 px (1 px は地上で約 140 m) |
| MINUSCA (中央アフリカ) | 関門を全て通った。基準点 26、LOO の最大 2.3 px (1 px は約 1 km) |
| UNMISS (南スーダン) | 関門を全て通った。基準点 21、LOO の最大 2.4 px (1 px は約 1 km) |
| MONUSCO (コンゴ民主共和国) | 失敗の宣言。affine では基準点の広がりが足りず (凸包 12%)、poly2 では LOO が 5.4 px。地図の投影の曲がりが大きい |
| UNISFA (アビエイ) | 失敗の宣言。小さな村の名前で、OSM に見つかる名前が少ない (6 つそろわない) |

- 通った 2 件は、重ね合わせを OSM の地図の上に描いて、町の名前、道路、国境が重なることを目で確かめた。
- 残りの誤差は、地図の記号の位置と OSM の町の点の違いで、2 px 前後 (UNMIK で約 400 m)。記号を画素未満の精度で求めても変わらなかった。
- 基準点に残す許容 2 px は、UNMIK で決めた。3 px では LOO の最大が 3.6 px になり、関門 (3 px) で落ちた。関門は緩めていない。

## スクリプト

| スクリプト | 役割 |
|---|---|
| `scripts/name_gcps.py` | 記号の検出、名前の当てはめ、記号の選択、基準点 |
| `scripts/pdf_words.py` | PDF の文字の層から語、句、記号フォントの字を取り出す。フォントの大きさは字のゆるい箱の高さから取る (書き出しによっては 1 と返る) |
| `scripts/ocr_words.py`、`scripts/nominatim.py`、`scripts/place_hint.py`、`scripts/geometry.py` | place-hint と同じもの (写し) |
| `scripts/transforms.py` | georef-gates と同じもの (写し) |

テスト:

```sh
uvx --with numpy --with opencv-python-headless --with scikit-image --with pypdfium2 --with pytest pytest scripts/
```
