# unit-symbols

部隊配置図の部隊記号は、青い枠、右のラベル、枠の上の規模の印、枠の中の兵科の記号か略語、枠から場所へ引く線でできている。ベクタで描かれた PDF なら、これらは全て描画と文字の層にあり、画像として読む必要がない。

記号の規則の正本は、国連の軍事記号の手引き (UN Military Symbols Handbook, DPKO, 2000) である。規模の印は p.26、位置を表す線は p.28 に当たる。手引きに兵科の表はないので、兵科は NATO APP-6 により、1 つの記号ごとに目で確かめて決めた。

## 使い方

```sh
uvx --with pypdfium2 --with numpy --with opencv-python-headless \
  python scripts/unit_symbols.py map.pdf --out units.json --debug overlay.png
```

`units.json` は、重なり合う部隊の積み (stack) の並びである。各積みに次が入る。

- `units`: 部隊ごとの `label` (枠の右の文字)、`inner` (枠の中の略語)、`signature` (枠の中の記号の形)、`size_marks` (枠の上の印)、`echelon` (規模)、`arm` (兵科)
- `location`: 位置 (ページの pt、原点は左上、`/Rotate` で回した後の表示のとおり) と、その決め方 `located_by`
- `candidates`: 位置が 2 つ以上に割れたときの候補

位置の決め方は 2 つある。

- `leader`: 積みから伸びる線の先が、場所の印 (青い点、記号フォントの印、小さな円) の上にある。手引きでは、線の先が正確な位置である。線の先が 1 つの場所に決まらないときは `ambiguous` として位置を付けない。
- `adjacent`: 線がなく、場所の印が積みのすぐ隣にある。

位置が付かない積みは `location` が null になる。付けられない理由を黙って補わない。

## 規模

枠の上の印から読む。

| 印 | 規模 |
|---|---|
| 輪 1 | チーム |
| 点 1、2、3 | 分隊、班、小隊 |
| 棒 1、2、3 | 中隊、大隊、連隊 |
| X 1、2、3、4、5 | 旅団、師団、軍団、軍、軍集団 |

## 兵科

枠の中の記号の形 (`signature`) を、歩兵、工兵、衛生、通信、ヘリ、固定翼、砲兵、輸送、河川に対応付ける。記号がなく略語が書かれているときは、HQ、SHQ、FHQ、UNMO、FPU、IPO、MP、QRF、SF、SOF、EOD、MLT、PSU を、司令部、軍事監視員、警察部隊などに対応付ける。どちらでも決まらなければ null にする。

## 回した PDF

`/Rotate` で回したページでは、パスも文字も回す前の座標で返る。このスキルは、描いたページと同じ回した後の座標に直して返す。

## 限界

- ベクタで描かれていない PDF (スキャン) は読めない。
- 位置は、場所の印と線の先が一致した分だけである。位置が付かなかった部隊は、そのまま残る。
- 兵科は、これまでの地図で見つかった記号の形だけを知っている。知らない形は null になる。
