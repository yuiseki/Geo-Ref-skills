# deployment-geojson

部隊配置図の部隊を、地図の画素から経緯度の点にする。部隊の読み取りは `unit-symbols`、基準点の作成は `deployment-batch` が行い、このスキルはその結果をつないで、GeoJSON にする。

## 使い方

```sh
uvx --with numpy --with opencv-python-headless --with pypdfium2 --with pillow --with scikit-image \
  python scripts/deployment_geojson.py --results work/results.jsonl --runs work/runs --src pdfs --out geojson
```

- 地図 1 枚につき 1 ファイルを、`<ミッション>_<日付>_<PDF のハッシュ 12 桁>.geojson` の名前で書く。ファイル名に参照番号は入らない。
- `summary.jsonl` に、地図ごとの部隊数、位置が付いた数、付かなかった理由の内訳を書く。
- 同じ PDF (同じハッシュ) が 2 つあるときは、1 つだけ書く。
- 道具のコミットは、リポジトリの HEAD である。道具のファイルが未コミットか変更中なら、書き出しを止める。コミットを渡したいときは `--tool-commit` を使う。

## どの点を使うか

地図の本体と、枠で描かれた拡大図を、それぞれ別のパネルとして扱う。部隊の位置を含む最も小さい (細かい) パネルを使う。

- 関門を全て通った地図のパネル: そこにある部隊の全て。
- 点の広がりの関門だけで落ちたパネル (部隊の枠が拡大図の空きを取る、町が地図の一部にしかない): 部隊の点が、基準点を結んだ範囲 (凸包) の内側にあり、基準点を 1 つずつ抜いたときの点の動きが 3 px 以下のときだけ使う。画像全体の答えとしては、使わない。
- それ以外の関門で落ちたパネル: 使わない。

基準点を抜く確かめだけでは足りなかった。基準点が全て地図の西側にある MINUSMA の図では、北東の部隊が 13〜18 km ずれていたのに、点の動きは 1.2 px だった。当てはめが基準点の外で曲がることを、この確かめは見ない。そのため、凸包の内側にあることも求める。

使われなかった部隊は、理由別に数えて `summary.jsonl` に残す。

- `no_location`: 部隊の積みに位置が付かなかった
- `outside_panels`: どのパネルにも入らない
- `outside_hull`: 局所のパネルで、基準点の範囲の外
- `uncertain`: 局所のパネルで、点の動きが 3 px を超えた

## 出力

FeatureCollection の最上位に、`based_on` ("Based on United Nations map")、`disclaimer` (無保証、間違いの可能性、国連の製品でないこと)、`mission`、`map_date`、`source_sha256`、`tool`、`tool_commit` を持つ。各点には次が入る。

| 欄 | 意味 |
|---|---|
| `label`、`inner` | 枠の右の文字、枠の中の略語 |
| `symbol`、`arm`、`echelon`、`size_marks` | 記号の形、兵科、規模、規模の印 |
| `nearest_text` | 点のそばの一番近い単語。地名とは限らない |
| `located_by` | `leader` (線の先) か `adjacent` (印が隣) |
| `panel_local`、`map_ok`、`std_px` | 局所のパネルか、地図全体が関門を通ったか、点の動き (px) |
| `no_warranty` | 点を 1 つだけ取り出されても無保証が残る短い文 |

日付 (`date`、`map_date`) は PDF の作成日で、地図が表す時点とは限らない。

## 公開してよい形

国連の地図から作った派生物として、"Based on United Nations map" と書く。地図の参照番号は入れない。時期は入れてよい。元の PDF の SHA-256 と、道具のコミットを入れる。正確さは一切保証しない。

- 属性から、ファイル名の語 (`map`) と題名 (`title`) を除く。どちらにも参照番号が入る。
- 書き出しの前に、ファイル名と題名から 4〜5 桁の数字を参照番号として集め、出力の全文を探す。1 つでも残っていれば、書き出しを止める。
- 国連の名称そのもの (United Nations) は、`based_on` と `disclaimer` の中で出典として書く。略称 (MONUSCO など) は残す。

## 限界

- 部隊の位置は、地図の場所の印に、線の先が一致した分だけである。印と実際の地物の違い、地図の作図上のずれは、そのまま入る。
- `nearest_text` は一番近い単語を拾うだけなので、別の町の名前が付くことがある。
- 点の広がりだけで落ちた地図の点は、地図全体の答えとしては関門を通っていない。`map_ok` が false のものとして、分けて扱う。
